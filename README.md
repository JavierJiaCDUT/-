# Retro Paper Terminal

A retro-styled typewriter application that simulates a vintage Motorola terminal/beeper device. Type text into the terminal and watch it print onto draggable paper cards with authentic typewriter animation effects.

View the original app in AI Studio: https://ai.studio/apps/drive/1nenBsSgoqKnzBuioSv-MTj3QTaWN7ooR

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app:
   ```bash
   npm run dev
   ```

3. Open your browser at `http://localhost:3000`

## Features

- Retro Motorola Fix-Beeper terminal interface with CRT screen effects
- Typewriter animation on output cards (50ms per character)
- Drag and drop paper cards to organize your desk
- Power toggle to simulate device on/off
- No backend required - runs entirely in your browser
